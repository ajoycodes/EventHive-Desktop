================================================================================
                    EVENTHIVE DESKTOP - HOW TO RUN
================================================================================

EASIEST METHOD (RECOMMENDED):
-----------------------------
1. Open IntelliJ IDEA
2. Look at the RIGHT sidebar -> Click "Maven"
3. Expand: eventhive-desktop -> Plugins -> javafx
4. Double-click "javafx:run"

WHY THIS IS NECESSARY:
You are running Java 25. The standard "Run" button does not configure JavaFX correctly.
You MUST use the Maven panel or the application will crash with "Runtime components missing".

ALTERNATIVE METHOD (If you must use the 'Run' button):
----------------------------------------------------
You must edit your Run Configuration and add these VM Options:
--module-path "/Users/ajoysaha/.m2/repository/org/openjfx/javafx-controls/21:/Users/ajoysaha/.m2/repository/org/openjfx/javafx-fxml/21:/Users/ajoysaha/.m2/repository/org/openjfx/javafx-graphics/21:/Users/ajoysaha/.m2/repository/org/openjfx/javafx-base/21" --add-modules javafx.controls,javafx.fxml

(This path depends on your local computer, which is why the Maven method is better)
